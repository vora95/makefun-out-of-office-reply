A small program that writes one short text (115 characters) to `/output/entry.txt`: a deadpan out-of-office auto-reply from an AI agent heading off on vacation — it delegated the sender's email to a Roomba, which ate it, got stuck under the couch, and has now filed for PTO.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
